# Basic Calculator

A simple and responsive calculator built using HTML5, CSS3, and JavaScript.

## 📌 Description

This project is a basic calculator that performs arithmetic operations such as:

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations

It also includes Clear and Equals functionality.

## 🎯 Objective

The main objective of this project is to practice:

- JavaScript event handling
- Arithmetic operations
- DOM manipulation
- Functions
- Conditional statements
- CSS Grid

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal values
- Clear button
- Equals button
- Divide-by-zero handling
- Responsive calculator interface
- No `eval()` function used
